Fixes hall-effect trigger deadzone stutter (that annoying blip in the low pressure range that ruins trailbraking) and adds rich haptic feedback, all running directly inside the game via CSP Gamepad FX.

problem-of-deadzone.gif

Requirements: CSP 0.2.0+ (mine is 0.2.11)

Main Features:

Independent Right/Left Trigger tuning
Adjustable response curve for each trigger: dull light presses for a less twitchy throttle, or sharpen them for a quicker brake bite
Vibration feedback for trigger input with selectable motor (low/high frequency)
Telemetry-driven haptics: tire slip, kerbs/road surface, ABS activation, collisions, g-force/suspension, off-road, engine RPM, and gearshifts
Installation:

Open the Gamepad Tweaks folder, and copy the extension and apps folders.
Paste both folders into your main assettocorsa folder.
You can try installing via CM first, but in some cases it doesn't extract all the files. So manual extraction is recommended.

Once installed, set a few things:

Open Content Manager → Settings → Custom Shaders Patch → Gamepad FX.
Make sure "Active" is checked, and select "Gamepad Tweaks" from the script dropdown.
Make sure Input Method is set to Gamepad (Settings → Assetto Corsa → Controls).
Start a driving session, then open Gamepad Tweaks from the in-game sidebar toggle app list to tune everything live.
