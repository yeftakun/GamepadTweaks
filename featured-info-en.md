# UI Feature Information

This document contains the English information text for each UI section. It has not been added to the tooltips or help text in the application yet.

## 1. Vibration Manager

Vibration Manager is used to configure the vibrations generated by game effects, such as tire slip, kerbs, ABS, collisions, G-force, off-road surfaces, engine RPM, and gearshifts.

## 2. Select Trigger to Configure (not needed; it is already explained in the short description)

## 3. Trigger Input

Hysteresis helps prevent small inputs or noise around the trigger's resting position from being interpreted as unwanted pressure.

- `Threshold Up` determines when the input becomes active.
- `Threshold Down` determines when the input becomes inactive again.

## 4. Input Indicator (Vibrate)

- `Proportional` mode follows the amount of trigger pressure. The greater the input, the stronger the vibration.
- `Static` mode uses a constant vibration strength while the trigger is active.

## 5. Trigger Smooth

Smooths sudden changes in the trigger signal. Use **Time Constant** to adjust the amount of smoothing.

Note: A higher value makes changes smoother, but the response will feel slower.

## 6. Trigger Sensitivity

Trigger Sensitivity controls the relationship between trigger pressure and the resulting output.

- `Knee X` determines where the curve changes.
- `Knee Y` determines how strongly the curve response is shaped.
- Presets are available as starting points for adjustment.

A curve below the straight line (the still-linear signal input) makes the initial pressure respond more slowly, which is suitable for trail braking. A curve above the straight line makes the final response slower, which is suitable for throttle control.

## 8. Signal Limit

### Status

This feature is available and is only shown when `Left Trigger (Brake)` is selected.

### Description

Signal Limit limits the maximum brake output. The limit is applied after Trigger Sensitivity.

Signal Limit is different from Brake Power. It only cuts the input within the `0–100%` range in a linear or 1:1 manner. A value of `100%` means that no additional limit is applied.

This feature is useful for cars that do not provide a built-in brake output limit in their setup.

### Short description

> Limit the maximum brake output linearly. This feature is only available for Left Trigger (Brake).

## Processing Hierarchy

```text
Raw Input
  ↓
Trigger Input
  ↓
Trigger Smooth
  ↓
Trigger Sensitivity
  ↓
Processed Signal
```

Signal Limit is applied after Trigger Sensitivity, specifically for LT/brake.
